# qa_python
# Тесты для класса BooksCollector

## Описание проекта

Данный проект содержит набор тестов для класса `BooksCollector`, который представляет собой систему для управления коллекцией книг с возможностью установки жанров, добавления в избранное и фильтрации.

## Реализованные тесты

#### `test_add_new_book_add_two_books`
- Проверяет корректное добавление двух различных книг
- Убеждается, что обе книги присутствуют в коллекции

#### `test_add_new_book_add_same_book_three_times_book_added_once`
- Проверяет, что при многократном добавлении одной и той же книги
- Книга добавляется только один раз (исключаются дубликаты)

#### `test_add_new_book_add_border_book_name` 
- Проверяет добавление книг с пограничными значениями длин названий:
  - Минимальная длина (1 символ)
  - Максимальная длина (40 символов)
- Убеждается, что такие названия корректно обрабатываются

#### `test_set_book_genre_set_valid_genre_for_existing_book`
- Проверяет установку допустимого жанра для существующей книги
- Убеждается, что жанр корректно сохраняется

#### `test_set_book_genre_cannot_set_genre_for_nonexistent_book`
- Проверяет обработку попытки установить жанр для несуществующей книги
- Убеждается, что система корректно обрабатывает такой сценарий

#### `test_get_books_with_specific_genre_returns_correct_books`
- Проверяет корректность фильтрации книг по конкретному жанру
- Убеждается, что возвращаются только книги указанного жанра

#### `test_get_books_for_children_returns_only_child_friendly_books`
- Проверяет фильтрацию детских книг (исключает возрастные ограничения)
- Убеждается, что возвращаются только подходящие для детей книги

#### `test_add_book_in_favorites_add_existing_book_to_favorites`
- Проверяет добавление существующей книги в избранное
- Убеждается, что книга появляется в списке избранного

#### `test_delete_book_from_favorites_remove_book_from_favorites`
- Проверяет удаление книги из избранного
- Убеждается, что книга корректно удаляется из списка

#### `test_get_list_of_favorites_books_returns_favorites`
- Проверяет получение полного списка избранных книг
- Убеждается, что возвращаются все добавленные в избранное книги

#### `test_get_book_genre_returns_correct_genre`
- Проверяет корректность получения жанра книги по её имени
- Тестирует различные сценарии: существующая книга с жанром, книга без жанра, несуществующая книга

#### `test_get_books_genre_returns_full_dict`
- Проверяет получение полного словаря books_genre
- Убеждается, что возвращается корректный словарь со всеми книгами и их жанрами
